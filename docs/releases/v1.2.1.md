# Fucknotes 1.2.1

Download **Fucknotes-1.2.1.apk** below and install it over the existing app. This APK uses the same signing certificate as 1.1.0 and 1.2.0 and keeps existing notes and settings.

- **One dark mode:** dark mode is a single switch in the editor menu, and its pages are true black. New notes always start light. The light / dark / pitch-black choice is gone from the New notebook dialog and the Paper sheet. Notes saved as pitch black in 1.2.0 open in dark mode.
- **Exports follow the note:** exports no longer ask for light or dark. Each note is exported in its own mode, including shelf exports and Drive uploads. Dot paper exports with finer 1.2 pt dots.
- **Ink colour repair:** strokes that an old pen-lift bug stored in their night colour are read back in the pen they were written with, so a line no longer changes shade partway or disappears from an export.
- **Toolbar on one row:** on a tablet the note bar and the pen bar share one row, upright and lying down. When the bar is tight, the tools that do not fit go behind a **More tools** button; pens are never hidden there.
- **Toolbar items:** ⋯ → Toolbar items has a switch for every tool, pen and highlighter on the bar. The choice applies to all notes. The last pen cannot be switched off.
- **Hand-drawn shapes:** lines, arrows, boxes and circles are drawn with a light hand-drawn wobble and a single outline. Switch on **Clean lines** at the bottom of the Shapes menu for exact geometric shapes.
- **Red highlighter:** drawn as a lit red tube. Everything you write with it stays visible while you keep writing, holds for 1.5 seconds after the last lift, then fades over one second. It is still never saved, exported or added to undo history.
- **Paper colour:** choosing a note or paper colour switches the note to light pages so the colour is visible at once. Paper swatches are available in dark mode too, and light pages no longer carry a blue tint.
- **Export one note from the shelf:** hold a note, then tap **Export PDF** in the selection bar. One note goes straight to the save dialog and exports as an editable PDF, the same as exporting from the editor.
- **Pen and gesture fixes:** a cancelled shape or lasso drag is discarded instead of committed, and a new pen stroke draws straight away after a pinch, even while fingers are still on the screen.

Validation: all 127 JVM tests pass and debug lint reports zero errors. The optimized release APK reports version 1.2.1 (code 4) and is signed with the same certificate as 1.2.0 (SHA-256 `a889393c…`). On the Xiaomi tablet, all 68 instrumented tests passed on 2026-11-13; after the single-outline shape fix that followed, the 17 drawing-tool tests passed again there. The full instrumented suite was not rerun after that fix, and no tablet was attached when this APK was built.
