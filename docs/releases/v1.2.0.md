# Fucknotes 1.2.0

Download **Fucknotes-1.2.0.apk** below and install it over the existing app. This APK uses the same signing certificate as 1.1.0 and keeps existing notes and settings.

- **Pitch-black pages:** choose Pitch black when creating a notebook, in Paper settings, or with the editor menu's Pitch black pages switch. The choice stays with the note. Handwriting, imported page backgrounds, previews, and dark PDF exports remain readable.
- **Shapes:** tap Shapes, choose Line, Arrow, Rectangle, or Circle, then drag on the page. Shapes remain editable vectors and support Select, move, duplicate, recolour, delete, undo, redo, and export. Regular handwriting keeps its original strokes.
- **Temporary red highlighter:** tap the red highlighter in the toolbar. Marks stay visible for 1.5 seconds after pen lift, then fade over one second. They are never saved, exported, or added to undo history. Tap the tool again or choose a pen to resume writing.
- **Undo and Select included in this APK:** Undo remains available with the compact pen bar. Select circles strokes for moving, copying, recolouring, or deleting. Narrow windows use two toolbar rows to keep the tools accessible.
- **Editor fixes:** shapes commit correctly while a palm rests on the screen; pinching does not swallow the next shape. Typed-note annotations use the same drawing tools. Large drawings open without Android's cursor-size limit, and page position survives rotation.

The release also includes the previously unpublished Select tool, editable PDF and Drive support, per-note appearance, and pen input fixes already on main.

Validation: 98 JVM tests and all 60 instrumented tests passed on an Android 15 emulator. Release lint completed with zero errors; the optimized APK's signature and version metadata were verified. Physical Xiaomi pen hardware was not connected for this pass.
